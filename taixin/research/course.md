## 0. 一句话

**业务员不是不会卖，是越卖越忙、靠感觉成交、经验复制不了。泰欣把十年销售浓缩成一套「销售公式」：
把生活放最前面，从效率下手，用工具把名单、跟进、报价这些重复动作系统化，再用懂人性把成交率拉高，
最后把时间、身体、家庭夺回来。**

他自己的话（转写 / 4U 导师页 / Threads）：
- 「你做對什麼事，而不是你做了多少事」
- 「很努力卻被業績追著跑？不推苦勞，用實戰 SOP 讓賺錢變標配」
- 「銷售不是感覺，銷售是心理學，銷售是統計學」「銷售是吸引不是推銷」
- 「教的是銷售其實是人生；學的是公式其實是感覺；學的是流程其實是賺錢」
- 「使命：幫每個人奪回時間、身體、家庭」

## 1. 解决什么问题（四层，按他的顺序）

| 层 | 学员的原话 / 症状 | 泰欣的解法 |
|---|---|---|
| 顺序反了 | 「很努力卻被業績追著跑」「業績很好但生活一團糟」 | 公式把「生活」放第一位：生活 → 效率 → 名单 → 成交 → 业绩 → 获利；执行从效率下手 |
| 重复劳动吃时间 | 「800 个联络人手动发讯息一次只能 15 个」「每次翻聊天记录找客户资料」「一天两三小时在打字、建档、报价」 | 工具化：通讯录/CRM 建档、客户分群、Line 自动发送与群发、报价程式、AI 语音转记录 |
| 靠感觉成交 | 「做了 3 年还是靠感觉」「客户越来越多业绩没跟上」「不懂人就只剩降价」 | 三件事对照（名单 / 成交率 / 获利）、明确的跟进节奏、DISC 分型、先问再说、稳住价格 |
| 经验复制不了 | 「我以为大家都懂，其实从没把底层逻辑传给团队」「销冠很厉害，其他人学不会」 | 案例 + 可复制的系统：三天把销冠经验变成团队都能用的成交系统 |

学员回馈里出现最多的词：效率、工具、建档、名单、系统、SOP。最能用的一句：
「Top sales 也可以有自己自由的時間，原來是因為客戶管理系統做得超級好」。

## 2. 课程骨架

泰欣把所有销售工作压成三件事（视频《只要這三件事就懂銷售了》）：
**① 增加名单 ② 提高成交率 ③ 提高获利**。你做的事不在这三件里，方向就错了。
公式：**業績 = 數量 × 成交率**（4U 宣传片投影片）。

能从公开材料确认的板块（名称用他/学员的原词）：

| 板块 | 内容 | 出处 |
|---|---|---|
| 生活 / 心态 | 生活优先；专业是基线不是卖点；说实话；原则；第一步是解决自己内心的问题 | 转写 UhQRnC81IBM、Ik7xZJFMWaU、GB1_oUkjHDo、ErW1GrNxQ74；4U 宣传片 |
| 极致效率（電腦課） | 通讯录/CRM 建档与分群、Line 自动发送与群发、报价单/报价程式、行事历、AI 语音记录 | 副频道《極致效率學生反饋》；学员见证 Nces；回馈表 2022–2023 |
| 名单 / 流量磁铁 | 名单来源、网路开发、关键字投放、社群经营、潜客分群、「业务没有资格丢掉任何客户」 | 转写 lXxaYj6dWI8、6BS6goWqp2U；回馈表 |
| 跟进 / 关系（留） | 天网·地网·人网、五分钟内第一条讯息、每周出现七八次、信任是一百个一分、明确的跟进节奏 | 转写 drDRLHVT-Oo、bvDXiBTcABE、byCOf7FemW4；学员见证 6KPoXQvcDto 标题 |
| 成交 / 人性（买） | DISC 分型、交易地图、异议处理六步 + Mini yes、「太贵了」四种意思、先问再说、稳住价格、成交是有预谋的策划 | 转写 zD7fAndCSCg、wVVXhlx77VQ、H_Ect59mH7c；4U 宣传片；回馈表 |

## 2b. 4U 三天版「超級銷冠系統」里被学员点名的模块（马来西亚场学员见证，2026）

| 学员 | 点到的内容 |

| Bryant（Macoin，应用开发顾问） | 第一天「成交地圖」：异议处理三轮、回应异议的六个问题、五大核心原则；「销售从解决客户的问题开始，顺序才对」。第二天：用系统跟进每一个名单；業績 = 名單 × 成交率；CSV 一键导入通讯录、一键群发 |

## 3. 课程形式与对象（4U 版）

- 三天实体课（Threads：10/16–10/18 開課；学员见证反复说「這三天」）。4U 版另有「孵化全球 1000 位 top sales」的计划和泰欣的私董会。
- 三种学员（他自己的分法）：新人（把方向做对，五年后比同事轻松）；做了 3–5 年卡瓶颈（要新方法新系统）；
  8–10 年老手（来验证 + 补理论，好复制给下面的人）。
- 马来西亚场以老板 / 团队领导为主（见证者多是创办人，诉求「复制给团队」）。

## 4. 对口播稿 CTA 的含义

- 桥是「时间被业绩吃掉」和「靠感觉、复制不了」，不是「学销售技巧」。
- Kenny 的 56 篇里讲忙、拖延、被看见、被替代、选择、顺序反了的，接「把时间赢回来」。
- 讲懂人、被拒绝、关系维护的，接「懂人性才不用降价 / 靠感觉」。
- 纯感情、看人、原则的，走互动 CTA。
