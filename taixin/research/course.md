## 1. 这个课程解决什么问题

一句话（泰欣自己的说法拼起来）：**业务员不是不会卖，是越卖越忙、生活被业绩吃掉；课程把销售变成一套有顺序的系统，用效率和工具把时间赢回来，再用「懂人性」把成交率拉高。**

拆开是三层：

1. **顺序反了**：多数人把业绩放前面、生活放后面。泰欣的公式把「生活」放最前面，
   生活好 → 效率 → 名单 → 成交 → 业绩 → 获利；执行时从效率下手。（转写 UhQRnC81IBM、Ik7xZJFMWaU）
2. **重复劳动吃掉时间**：打字、整理资料、报价、群发、追踪，一天两三个小时在做不该亲手做的事。
   解法是工具：CRM/通讯录建档、Line 自动发送与群发、报价程式、AI 会议记录与讯息。（转写 NYH2Ek0bIi0、5uVYz2TZxGk；学员回馈里出现最多的词就是「效率」「工具」「建档」「名单」）
3. **不懂人就只剩降价**：客户说贵、说考虑、不回讯息，新人只会降价或催。解法是人性：DISC 四型、
   先问再说、用细节和请教代替夸奖、信任是一百个一分的小动作、不丢掉任何一个客户。（转写 zD7fAndCSCg、wVVXhlx77VQ、0JfwdFMmN5U、drDRLHVT-Oo、lXxaYj6dWI8）

学员自己的话（回馈表原文）：
- 「Top sales 也可以有自己自由的时间，原来是因为客户管理系统做得超级好」
- 「工作是为了提升生活品质」「效率就是王道」「省下的时间真的都是赚到的」
- 「从业务生活到如何销售，销售变成一套完整的 SOP」
- 「用工程师思维建立的业务工具」「任何产业都适用的一套销售系统、工具」
- 「不好意思是你最大的敌人」「诚信 + 服务 = 我贵得心安理得」
- 学员最想再加强的：商谈/异议处理、名单累积后如何成交、实作演练

## 2. 课程板块（能从公开材料确认的）

泰欣口中的「销售公式」链条：**生活 → 效率 → 八大流程 → 找 / 留 / 买 → 名单更长 → 成交率更高 → 业绩 → 获利**。
围绕这条链，能确认的模块：

| 板块（泰欣/学员用词） | 内容 | 证据 |
|---|---|---|
| 极致效率（電腦課） | 通讯录/CRM 建档、Line 自动发送与群发、报价单/报价程式、行事历、AI 语音转记录 | 转写 6BS6goWqp2U、WRCFU1yK_N8、NYH2Ek0bIi0；回馈表 2022–2023 |
| 流量磁铁（找） | 名单来源、网路开发、关键字投放、社群经营、潜客分群 | 转写 6BS6goWqp2U；回馈表「名单」「网路开发」「关键字投放」 |
| 留（关系与追踪） | 天地人网络、五分钟内第一条讯息、每周出现七八次、不丢掉任何客户、信任一百个一分 | 转写 drDRLHVT-Oo、lXxaYj6dWI8、byCOf7FemW4、bvDXiBTcABE |

## 3. 对口播稿 CTA 的含义（等确认后再动）
